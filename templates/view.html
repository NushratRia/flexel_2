💡 Tips

Interaction Modes

🖱 WIMP Mode

The traditional mouse-and-keyboard system for clicking, typing, and navigating in the sheet.

🎙 Voice Mode

Control the sheet using your voice:

  • Say 'Flexee'.
  • And say your command (e.g., “sort column A”).
  • The system will execute the task hands-free.

Example Voice Commands:

📌 Selecting
  • “Select A1”
  • “Select B2 to D5”
  • “Scroll down to row 10” / “Scroll up to row 1”
  • “Scroll to row 20”
🗑️ Deleting
  • “Delete A2” / “Clear B3:D4”
  • “Delete this” (while pointing with hand)
  • “Remove B5”
  • “Clear C2”
✍️ Writing
  • “Write 50 in C2”
  • “Write hello here” (points to current target)
  • “Put 5 in C10”
  • “Fill 0 into B5”
📋 Copy / Paste
  • “Copy A1:C3”
  • “Copy this” (with gesture target)
  • “Paste into D5”
  • “Paste here”
🔄 Undo / Redo
  • “Undo”
  • “Redo”
🔍 Zoom
  • “Zoom in”
  • “Zoom out”
📊 Data ops
  • “Sort column A ascending”
  • “Sort column B descending”
  • “Sum C5 to C10”
  • “Average D4 to D20”
⚡ Extended
  • “Go to cell F10”
  • “Select the fifth row” (ordinal numbers supported)
  • “Scroll to line 50”
  • “Write 3.14 here”
  • “Copy column B” → “Paste into column D”

🖐 Gesture Mode

Perform tasks with hand gestures:

  • Selecting: Pinch fingers together on the target cell.

⚡ Combination Mode

Use all the above interaction methods together. For example:

  • Point to data with a gesture and say a voice command like “sort this.”
  • Switch between WIMP, Voice, and Gesture seamlessly in the same workflow.
